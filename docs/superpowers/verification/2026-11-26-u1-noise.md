**What A3 found on the way**, each fixed at its cause:
1. **W009 on every program.** It is false here: truST's runtime at `6405915` runs every PROGRAM at each cycle, in a task
   or in the background (`runtime/cycle.rs`, `execute_background_programs`).
   - W009 is dropped when it names a PROGRAM.
   - A block nothing calls keeps it (`a_program_is_never_unused_but_a_block_nothing_calls_is`).
2. **A real W004 in `sort_line` and `code_sort_line`:** a step chain's CASE without ELSE.
   - They gain `ELSE step := 0;`, which no run reaches.
   - The engine's line tests pass unchanged (22/22), and so does the agent's code-sort test.
3. **Build warnings on four examples,** such as "belt_a.running at %IX0.2: the program does not declare it": feedback
   the program leaves unread.
   - Such a plant signal into the PLC is now a note (`Controller::unread`), sent as `hints` by Build, the app's MCP and
     the agent.
   - An undeclared output or panel button stays a warning (`an_undeclared_output_or_button_warns`).
4. **A false "No problems detected".** The pane said it before the analysis answered, and the first E2E run passed on
   that.
   - The pane now says "Checking the program…" until the answer for the texts shown.
   - The E2E waits for the verdict.
