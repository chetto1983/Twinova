# Verification: UX audit of the v0.4.0 release

Date: 2026-11-26. No spec: this is the measurement taken before one, after the user's verdict that the UI is not
presentable and that "the UX of an industrial simulator is missing". The comparison with Open Industry Project is in
`docs/research/21-oip-funzionalita.md`.

## How it was measured

- **Build:** `Twinova_0.4.0_amd64.AppImage` from the v0.4.0 release, extracted and started under Xvfb (1920 × 1080
  screen) with `LIBGL_ALWAYS_SOFTWARE=1` and `WEBKIT_DISABLE_DMABUF_RENDERER=1`, as CI's E2E runs it. The container
  lacked `libEGL.so.1`; `libegl1`, `libgl1`, `libgles2` and `libgl1-mesa-dri` were installed with apt to start it.
- **Driving:** `twinova-agent` from the same AppImage, attached to the open window over MCP: `open_example`, `build`,
  `run`, `select`, `show`, `screenshot`.
- **Window sizes:** the default 1440 × 900, then 1366 × 768 (resized with xdotool).
- **Scenes:** the `sort_line` and `code_sort_line` examples, built and running at 1×.

## What was seen

- **Inspector, stopper selected while running** ([picture](img/2026-11-26-ux-audit-inspector.png)):
  - signals show their address as editable text (`%QX0.5`, `%IX0.4`), with `PLC` and `TAG` badges, and no live value;
  - the move gizmo stays on the part while the line runs.
- **Watch** ([picture](img/2026-11-26-ux-audit-watch.png)):
  - the I/O list shows about 5 rows in the default dock;
  - "Operator panel" has a heading and nothing under it: the examples declare no panel buttons
    (`WorkspaceDock.svelte`).
- **Problems** ([picture](img/2026-11-26-ux-audit-problems.png)): 23 entries on `sort_line`, 25 on `code_sort_line`,
  while the build reports `"warnings":[]`. Among them:
  - `W009 unused program 'Main'`, though `Main` is the program the task runs;
  - `W001 unused variable` on I/O declared for the panel;
  - `W008 Cyclomatic complexity 20 exceeds 15`.
- **PLC dock at 1366 × 768** ([picture](img/2026-11-26-ux-audit-1366-plc.png)): one line of code and one and a half rows
  of the variables table are visible.
- **PLC dock, other observations:**
  - the component behaviours (`twinova.belt@1`, …) are listed as the PLC's "Function blocks", beside the line program;
  - the variables table repeats the VAR block the text shows below it.
- **Scene:** the warehouse decoration takes about half the viewport at the opening camera, and no sensor, actuator or
  signal state is drawn in 3D.
- **Correction to an earlier claim:** the catalogue shows real thumbnails. The generic cube icons were in a CI
  screenshot of 2026-11-23.

## What this does not show

- Interaction quality (drag, snap, gizmo feel): only static states were captured.
- Speed: the real-time factor read 0.55–1.0× under software rendering, which says nothing about a GPU machine.
- Windows: not run.
- Anything about a person's understanding: no task-based test with a user was run yet.
